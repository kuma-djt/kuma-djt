I build tools for running AI agents: harnesses, terminals, and the plumbing that lets a few agents work the same job without stepping on each other.

Most of it lives in private repos. The public one is [lillignode](https://github.com/kuma-djt/lillignode), a terminal that runs several Claude Code agents side by side, each in its own folder, with a sidebar that tells you what each one is doing. It's v0.1 and rough. Issues and ideas are welcome.
